- **Whether `openapi.yaml` matches `gen_openapi.py`.** Running the generator might write a file, so I did not. Its line 136 does carry the same reasons enum.
- **`x-pack` coverage.** `check_openapi.py` has no check for it; I verified it by reading. I did not re-count the "8 public, 30 signed-in, 19 owner" figures in `api.md` §1.
- **The urgent mark in the executable model.** The model has no emergency event. The document says so, so the mark's behaviour rests on the prose alone.
- **Sections outside the listed passages.** Dashboard design, the rest of the threat model and other ADRs were not reviewed, so stale booking or call-key text elsewhere would only have shown up in the greps.
- **Whether moving the booking rules out of core is workable in code.** Nothing is built.
